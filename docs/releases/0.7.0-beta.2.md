# Orbit 0.7.0-beta.2

This Swift prerelease separates metadata inspection from file-content reads at the native file-access boundary. Catalog/search can inspect and exclude pending non-note assets without requesting their bytes. Actual pending note or revision contents still refuse until downloaded; write/delete behavior and all 19 command schemas remain unchanged.

The companion app fixes canonical iCloud registration paths, shows current folder-link errors on the Orbits screen, retains pending folders with Download files/Refresh, and adds enforced read-only folder access for existing format-2 Orbits without migration. The app pins the exact published core source revision.

Disk format remains 3 for new writes, with existing legacy compatibility/migration routes preserved. No personal data migration or repair is performed by this update. Python remains development-only; production plugin/MCPB packages use the universal native executable.

Verification: 101 Swift core tests passed through MobileBuildMCP, including a failing-before/passing-after pending-image metadata regression and continued refusal of actual pending-content reads. Native-host/iCloud/real-model acceptance and comparative performance remain incomplete. The binary is ad hoc signed, not Developer ID notarized.

Update the existing Orbit marketplace installation and reopen the host. Keep the complete Orbit folder/history/assets and device-local state for rollback; do not restore an old Markdown-only backup over accepted history. See [transition/rollback](../swift-migration/transition.md) and [verification](../swift-migration/verification.md).
