# Orbit 0.7.0-beta.1

This prerelease switches the desktop MCP plugin and Claude MCPB to the shared Swift OrbitCore engine. All 19 tools and six skills ship together, with a universal Apple Silicon/Intel executable for macOS 13 or later. Python is no longer installed or required by the plugin. Its source remains in the development checkout as the temporary compatibility reference.

Orbit App consumes the same version through an exact Swift package revision. The companion app update enables ordinary explicitly selected folders, including iCloud Drive through the system picker. Bookmarks, marker identity, format support, safe paths, download availability, exact approvals and retry journals remain enforced. The special acceptance screen is not part of the normal app flow.

Disk format remains 3. Existing format-3 Orbits require only the migration compatibility check; no content or marker rewrite is needed for the language change. Formats 1 and 2 retain their existing explicit preview/apply/resume/rollback routes. Preserve complete revision histories, observations, sources, unknown metadata and recovery journals when moving or backing up a folder.

Update Orbit from the existing `aataraxiaa/orbit` marketplace, then open a fresh conversation. Claude Chat users install the new `orbit.mcpb` asset separately. The normal plugin name and MCP server key remain `orbit`; no separate acceptance marketplace is required. The GitHub source includes the native binary and resource bundle, so marketplace installation does not need a compiler, Python or a first-run download script.

The user authorized publication for normal in-app testing on 31 October 2026 instead of blocking on formal acceptance. Native desktop-host/fresh-conversation behavior, physical iCloud round trips, actual local-model execution and comparative performance remain unverified. Automated regression, differential and SDK checks cover their recorded cases; they do not establish those real-world results. This is a beta, not a claim that the complete migration has passed acceptance.

To roll back, stop all writers and reinstall Orbit 0.6.0. Keep the full folder and its immutable history; do not replace it with an older Markdown-only backup. The unchanged format and mixed Python/Swift fixtures support this runtime transition, but actual cloud delivery can still be incomplete. Inspect conflicts and pending operations before resuming writes. The app must retain the matching identity and explicit user-selected folder when relinking.
