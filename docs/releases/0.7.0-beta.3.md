# Orbit 0.7.0-beta.3

This packaging-only prerelease fixes Claude remote marketplace rejection of the top-level `bin/` directory (`marketplace_sync_bin_directory_not_allowed`). The native executable and matching resource bundle now live under `runtime/`. Claude, Codex and MCPB launch manifests and both package builders use the new paths.

The universal executable and resource bytes are unchanged from beta.2. Installable package manifests identify beta.3; MCP initialization and the shared OrbitCore implementation remain beta.2. No Swift rebuild or signing change is included.

Disk format remains 3. Note schemas, metadata, identities, original sources, folder layout and persistent state do not change. Existing format-3 Orbits need only the read-only compatibility check in the migration skill. Legacy migration routes, backups, interruption recovery and safe reruns remain unchanged. Updating this plugin does not authorize a personal data migration.

Mechanical verification passed with Python 3.14.6: 193 regression/package tests, isolated smoke and package assembly. Extracted launch manifests discover all 19 tools; relocated resources support setup, save, read and search across fresh native processes. The binary SHA-256 remains `10b4f7dd9feea272bfe0b57352e2d6752a5c87cca91f963bdaad245c53f1a3f6`.

Update the existing Orbit marketplace installation and reopen the host. Mechanical extracted-package launch checks do not establish that Claude's remote marketplace has accepted the update or that every desktop host can install it. Preserve complete Orbit data and device-local state for rollback as described in [transition guidance](../swift-migration/transition.md).
